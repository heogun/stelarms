# 05. 제작 · IP · 로드맵

> 팬게임에서 가장 중요한 문서. **"만들 수 있는가"보다 "배포해도 되는가"** 를 먼저 정한다.

---

## 1. 아트 디렉션

### 1-1. 톤

- **"무대 뒤의 별"**: 화려한 아이돌 조명 + 밤하늘 + 각 스트리머의 모티프.
- 지나친 유혈/공포 표현은 지양. 뱀파이어·저주 모티프는 **고딕 판타지** 톤으로.
- 모든 일러스트는 **전연령**. 노출·성적 표현·과도한 신체 강조 금지.
- 4기생처럼 데뷔 직후인 멤버는 **공식 프로필 이상의 설정을 단정하지 않는다.**

### 1-2. 카드 프레임

| 위치 | 정보 |
| --- | --- |
| 상단 좌측 | 적정거리 (공격만) |
| 상단 우측 | 소모값 (비장패만) |
| 중앙 | 일러스트 |
| 하단 좌측 | 오라/라이프 데미지 (공격만) |
| 하단 중앙 | 카드 텍스트 |
| 하단 우측 | 봉납 (부여만) |
| 테두리 | 타입 색(빨강/파랑/초록) + 스트리머 대표색 |

- 카드 타입은 **색 + 아이콘**을 함께 사용한다. 색약 접근성.
- 텍스트는 최소 8pt(인쇄 기준). 한 카드에 4줄을 넘기지 않는다.
- 키워드는 **굵게 + 대괄호**.

### 1-3. 스텔라 카드 (선택용)

- 전면: 스트리머 초상 + 이름 + 기수 + 모티프 + 주 거리 + 난이도.
- 후면: 추천 페어, 시그니처 요약, "이 스트리머로 이기는 법" 3줄.
- 카드 크기는 스킬 카드와 동일하게. 선택 시 책상 위에 세워 둔다.

## 2. 인쇄 사양

| 항목 | 사양 |
| --- | --- |
| 카드 크기 | 63 × 88 mm (표준 TCG) |
| 해상도 | 300 dpi |
| 색상 | CMYK |
| 재단 여백 | 2 mm bleed |
| 안전 여백 | 3 mm |
| 용지 | 300g 이상, 매트/린넨 |
| 수량 | 44종 × 2장 = 88장 (기본판) |
| 토큰 | 25 mm, 2색 × 30개 |
| 거리 트랙 | 100 × 300 mm 또는 플레이매트 |
| 박스 | 2덱 + 토큰 + 룰북 수납 |

### 인쇄 전 체크

- [ ] 모든 카드 텍스트 오탈자 검수
- [ ] 카드 번호/희귀도/분류 일관성
- [ ] 재단선 밖으로 중요한 요소가 나가지 않았는가
- [ ] 실제 출력 1장으로 색/가독성 확인
- [ ] 토큰과 카드의 색 대비 확인

## 3. 디지털 프로토타입

### 3-1. 1단계: Tabletop Simulator

- 가장 빠르다. 카드 이미지 + 토큰 + 거리 트랙만 있으면 된다.
- 스크립트 없이 수동 진행. 룰 검증용.
- 장점: 원격 테스트, 즉시 배포.
- 단점: 룰 강제가 없어 판정 실수.

### 3-2. 2단계: 웹 프로토타입

- **핫시트(한 화면 번갈아)** 또는 **로컬 2인**부터.
- 기술 스택 예시: React + TypeScript + Zustand. 서버 없이 로컬 상태 머신.
- 반드시 **결정론적 상태**로 구현: 같은 입력 → 같은 결과. 리플레이 저장.
- 구현 우선순위:
  1. 거리/오라/플레어/라이프 상태
  2. 기본동작 5종
  3. 카드 사용/데미지/부여패
  4. 비장패/플레어
  5. 덱 구축 화면
  6. 리플레이/로그
- 온라인 대전은 **v1.0 이후**. 매칭/서버/계정은 범위 밖.

### 3-3. 디지털에서 조심할 것

- 공식 일러스트/로고/Live2D/음성을 **절대** 넣지 않는다.
- 카드 앞면 이미지는 직접 그린 팬아트 또는 라이선스 확보 아트만.
- 스트리머 이름/초상 사용에 대한 허가 범위를 확인한다.
- 수익화(광고, 후원, 유료 배포)하지 않는다.

## 4. IP 가이드

> 아래는 법률 자문이 아니라 **팬 프로젝트 운영 원칙**이다. 배포 전에 변호사/권리자 확인을 권장한다.

### 4-1. 기본 원칙

1. **비공식 팬메이드**임을 모든 페이지에 명시한다.
2. **비영리**로만 배포한다. 판매·광고·후원·크라우드펀딩 금지.
3. 공식 로고·일러스트·Live2D·음성·음악·UI를 사용하지 않는다.
4. 원작 게임의 카드 텍스트/일러스트/카드명을 복제하지 않는다.
5. 스트리머의 **공식 페르소나**만 사용한다. 실명·사생활·신상 정보 금지.
6. 졸업생은 기본적으로 제외한다. 포함 시 당사자/소속사 동의 필수.
7. 요청이 오면 **즉시 배포 중단**한다.

### 4-2. 허가 문의 템플릿

```text
제목: [팬 프로젝트 문의] 스텔라이브 팬메이드 카드게임 비영리 배포 관련

안녕하세요, 스텔라이브 팬 프로젝트 <STELARMS>를 준비하고 있습니다.
- 형태: 비영리 팬메이드 2인 카드게임 (인쇄용 PnP + TTS 모드)
- 사용 범위: 공식 프로필의 캐릭터 설정, 이름, 모티프만 참고
- 사용하지 않는 것: 공식 일러스트/로고/Live2D/음성/음악
- 배포: 무료, 수익화 없음
- 아트: 팬아티스트 외주 또는 자체 제작, 크레딧 표기

팬게임 가이드라인 또는 허가 가능 범위를 안내해 주시면 감사하겠습니다.
```

### 4-3. 아트 외주 계약 시 포함할 것

- 사용 범위: 팬메이드 카드게임, 인쇄/PnP/TTS, 비영리.
- 2차 수정(크롭/색보정) 허용.
- 크레딧 표기 방식.
- 프로젝트 중단 시 사용 중지.
- AI 생성물 사용 여부 명시.
- 특정 스트리머의 초상 사용에 대한 아티스트의 책임 범위.

### 4-4. 콘텐츠 안전

- 성적 표현, 과도한 폭력, 혐오, 정치적 메시지 금지.
- 실제 인물에 대한 비방/조롱 금지.
- 팬덤 간 분쟁을 카드 소재로 쓰지 않는다.
- "저주/불운" 같은 모티프는 **캐릭터의 서사**로 다루고, 실제 멤버의 불운을 희화화하지 않는다.
- 4기생의 "빨간약(전생)" 등 비공식 정보는 카드에 넣지 않는다.

### 4-5. 배포 채널

| 채널 | 허용 | 비고 |
| --- | --- | --- |
| 개인 블로그/깃허브 | O | PnP PDF, 카드 이미지 |
| Tabletop Simulator Steam Workshop | O | 무료 모드 |
| 팬카페/디스코드 | O | 커뮤니티 배포 |
| 인쇄 주문(공동구매) | △ | 원가 배포만. 소속사 확인 후 |

| 광고/후원 수익 | X | 비영리 원칙 위반 |

## 5. 커뮤니티 & 대회

### 5-1. 정기 플레이테스트

- 주 1회, 2~3시간, 4~8인.
- 초보 1명 + 숙련 1명을 같은 테이블에 배치.
- 끝나고 **"가장 기억에 남는 한 장면"** 을 공유. 밸런스보다 재미를 먼저 확인.

### 5-2. 토너먼트 규칙 (v0.2)

- 4~8명 참가. 전원이 연결된 상태에서 대회장이 시작한다.
- 3라운드 스위스 후 상위 4명이 4강(1-4, 2-3) → 결승을 치른다.
- **삼습일사**: 서로 다른 스텔라 3명 선택 → 상대 1명 밴 → 남은 2명으로 7+3 덱 구축.
- 온라인 대회는 픽·밴·덱 각 단계 5분, 본 경기 25분을 적용한다.
  오프라인 진행 시 덱 구축 3분을 권장한다.
- 스위스는 승 3점·무 1점·부전승 3점. 동률은 부흐홀츠 → 승수 → 시드 순으로 정렬한다.
- 본 경기 시간 초과 시 라이프가 높은 쪽이 승리한다. 라이프도 같으면 스위스는 무승부,
  4강·결승은 시드가 높은 쪽이 진출한다.
- 진행 중 이탈은 현재 경기 기권이며 이후 라운드에서 제외한다. 연결 끊김만으로는 즉시 기권하지 않는다.
- 금지 카드/에라타는 대회 공지에 명시.
- 참가비/상금 없음. 상품은 팬아트 엽서 등 비영리 굿즈.

### 5-3. FAQ 운영

- 룰 질문은 디스코드 채널에 모은다.
- 매주 1회, 공식 FAQ 문서로 정리.
- 에라타는 카드 인쇄본에 스티커로 부착할 수 있게 번호를 남긴다.

## 7. 리스크 관리

| 리스크 | 영향 | 대응 |
| --- | --- | --- |
| 소속사 허가 거부 | 배포 불가 | 개인용으로만 제작, 공개 배포 중단 |
| 아트 품질 편차 | 게임 신뢰도 하락 | 스타일 가이드 + 1명 아트 디렉터 |
| 밸런스 붕괴 | 재미 하락 | 4인부터 단계적 출시, 20판 단위 패치 |
| 4기생 설정 변경 | 카드 수정 | 4기생은 확장으로 미루고, 프로필 1문장만 사용 |
| 멤버 졸업/논란 | 카드 삭제 필요 | 로스터 모듈화, 카드 번호별 교체 가능 |
| AI 아트 논란 | 커뮤니티 신뢰 | AI 사용 여부 공개, 아티스트 크레딧 |
| 상표/저작권 문제 | 법적 분쟁 | 비영리, 자체 아트/텍스트, 즉시 중단 |
