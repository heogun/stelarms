# 02. 스텔라 로스터

> "여신 카드를 스트리머에 맞게" 바꾸는 작업의 핵심 문서.
> 각 스트리머를 **공식 설정 → 게임 역할 → 시그니처 → 카드 풀** 순서로 설계했다.

---

## 1. 매핑 원칙

1. **공식 설정 우선.** 팬덤 밈은 카드 이름의 맛을 더하는 정도로만 쓴다.
2. **한 스트리머 = 한 가지 판타지.** "이 캐릭터를 고르면 무엇을 하고 싶어지는가"를 한 문장으로 정의한다.
3. **거리대를 겹치지 않게.** 14명이 모두 같은 거리에서 싸우면 조합의 의미가 없다.
4. **시그니처는 카드 텍스트 안에서 완결.** 새 전역 규칙을 만들지 않는다.
5. **세기는 설정이 아니라 플레이로.** 강한 설정은 강한 카드가 아니라 **고위험·고보상**으로 표현한다.

> 여기서 "시그니처"는 전역 키워드가 아니라, 그 스트리머의 카드에서 반복되는 고유 메커니즘을 뜻한다.

### 1-1. 원작 여신 플레이스타일 대응

원작의 모든 여신을 1:1로 대응시키는 것은 비추천한다. 원작은 20명 이상이고, 스트리머는 14명이라 숫자가 맞지 않는다. 대신 **기본판 4여신의 플레이스타일 축**을 참고해 새로 설계했다.

| 원작 여신 | 원작 플레이스타일 | STELARMS 대응 | 변환 포인트 |
| --- | --- | --- | --- |
| 유리나 | 중거리 콤보, 라이프 3 이하에서 강화 | **유니** | 결사 → 각성(라이프 5 이하) |
| 사이네 | 근거리 연격, 콤보 | **마시로 / 리코** | 연격 → 기본동작 추가 / 연참 |
| 히미카 | 원거리 저격, 높은 화력 | **히나** | 원거리 유지 + 빙결 |
| 토코요 | 방어·서포트, 오라 조작 | **후야 / 린** | 서포트 → 성광 / 덱 조작 |

> "원작의 어떤 여신을 그대로 옮긴다"가 아니라, **"원작에서 이 캐릭터를 좋아했던 사람이 다시 느낄 수 있는 플레이 감각"** 을 목표로 한다.

## 6. 졸업생·게스트 정책

### 아이리 칸나 (졸업)

- 기본 로스터에서 **제외**한다.
- 팬 요청이 많을 경우 "레거시 카드"로만 제공하되, **당사자와 소속사의 동의 없이는 배포하지 않는다.**
- 추모 목적의 카드에 공격적인 효과를 넣지 않는다.

### 강지 (대표/게스트)

- 토너먼트 로스터에서 제외한다.
- 이벤트용 **보스전** 전용 카드로만 사용한다. (`01_rules.md` 11-3)
- "사장님" 캐릭터를 희화화하는 효과는 피한다. 팬게임의 톤은 존중을 기본으로 한다.

## 7. 4기생 운용 메모

4기생은 데뷔 직후라 다음이 아직 정해지지 않았다.

- 공식 대표색
- 추가 세계관/관계성
- 팬덤명과의 연결

따라서 **기본판과 1차 확장(8인)에는 1~3기만** 넣고, 4기생은 **2차 확장 이후 설정이 어느 정도 굳은 뒤** 추가하는 것을 권장한다.
카드 컨셉은 "데뷔 프로필의 한 문장"에서만 뽑았으므로, 추후 공식 설정이 추가되면 카드 이름과 효과를 조정한다.
