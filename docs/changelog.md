# 변경 이력

## v0.5 — 2026-10-24 (룰 엔진 + 온라인 대전)

카드 데이터를 실제로 판정하는 **룰 엔진**과, 서버가 상태를 소유하는 **온라인 대전**을 추가했다.
카드 뷰어·덱 빌더는 그대로 유지되고, `#play` 탭에서 추천 덱으로 2인 대전을 할 수 있다.

### 룰 엔진 (`src/engine/`)

- **순수 TypeScript**: DOM/네트워크에 의존하지 않고, 상태는 직렬화 가능한 데이터만 쓴다.
- **결정론적 RNG**: xoshiro128** 시드 RNG로 셔플·랜덤 효과를 재현한다.
- **불변 적용**: 모든 액션은 `structuredClone` 후 적용하고, 실패하면 `RuleError`를 던져 원본을 바꾸지 않는다.
- **카드 154장 효과**: Op DSL과 카드별 프로그램 레지스트리로 공격·행동·부여·비장패를 구현했다.
- **pending 흐름**: 선택(`choice`)·정렬(`order`)·페널티를 `resume` 연속 실행으로 처리한다.
- **공격 해결**: 선언 → 대응(추가 대응 가능) → 방어(오라/라이프) → 데미지 → 【공격후】.
  오라 데미지는 상한 5를 먼저 적용한 뒤 정적 감소를 적용한다.
- **정보 은닉**: `toPlayerView`가 상대 손패·패산·덮음패·비장패와 pending 내부 `resume`/`ctx`를 숨긴다.
- **리플레이**: 액션마다 상태 해시를 기록해 같은 시드+액션 목록의 재현을 검증할 수 있다.
- **테스트**: 엔진 테스트 30개 + 렌더 테스트 3개(218 expect). 무작위 퍼즈 30게임에서 소프트락 없이 종료됨을 확인했다.

### 룰 변경

- **기본동작 횟수**: 턴당 기본 1회 + 카드 효과로 얻는 추가 횟수로 확정했다.
  기존 문서의 "원하는 만큼"과 다르므로 `01_rules.md` 5-2·6·10-2와 Q&A를 갱신했다.
- 이동·오라 상한·재구성·첫 턴 개시 페이즈 생략은 엔진 동작에 맞춰 문서와 대조했다.

### 서버 (`server/`)

- **Bun WebSocket 서버**: `/ws`에서 방 생성/참가/재접속/덱 변경/시작/액션을 처리한다.
- **서버 권위**: 좌석과 소켓을 묶고, 액션 스키마와 턴/페이즈/pending을 검증한 뒤에만 상태를 갱신한다.
- **방 코드**: 혼동 문자를 제외한 6자리. 재접속은 방 코드 + 1회용 비밀 토큰으로만 허용한다.
- **턴 타이머**: 기본 90초. 시간이 지나면 기본 액션을 자동 수행하고, 불가능하면 기권 처리한다.
  행동자 연결이 끊기면 타이머를 멈춘다.
- **방어**: 16KB 메시지 제한, 연결당 토큰 버킷(12/초, 버스트 6), 방/연결 수 제한,
  정적 파일 경로 traversal 차단.
- **배포**: `bun run serve`가 `dist` 정적 파일과 WebSocket을 같은 포트에서 서빙한다.

### 클라이언트

- **대전 탭**: 로비에서 이름·추천 덱을 고르고 방을 만들거나 6자리 코드로 참가한다.
- **보드**: 라이프/오라/플레어/더스트/집중력, 거리, 손패, 비장패, 부여패, 상대 요약, 로그, 해시.
- **pending UI**: 멀리건·개시 페이즈·대응·방어·손패 정리·페널티·선택·정렬·대기 상태를 모두 렌더한다.
- **액션 UI**: 기본동작 5종, 집중력/손패 코스트 전환, 카드 사용, 전력 행동, 턴 종료.
- **재접속**: `sessionStorage`에 방 코드/토큰을 저장하고, 새 연결마다 자동 resume한다.
  재접속 중에는 로비 대신 "재접속 중" 화면을 보여 준다.
- **종료**: 기권과 게임오버 오버레이, 로비 복귀.
- **반응형**: 좁은 화면에서 보드/로그/좌석을 세로로 쌓는다.

### 검증

- `bun test`: 33 pass / 218 expect.
- `bunx tsc -b`, `bunx tsc -p server/tsconfig.json`: 통과.
- `bun run build`: 통과. `bunx oxlint src server`: 오류 0, 경고 0.
- 서버 E2E: 생성/참가/시작/멀리건/정보 은닉/불법 액션/기본동작/재접속/나가기.
- 타임아웃 E2E: `STELARMS_TURN_MS=400`에서 자동 멀리건·턴 종료·손패 정리.
- 브라우저 E2E: 두 탭으로 로비→방→시작→멀리건→전진→턴 종료→손패 정리→개시 페이즈→새로고침 재접속→기권/게임오버.
- 렌더 테스트: 메인, 공격→대응→방어, 선택/정렬, 게임오버가 렌더됨.
- SSR 렌더 스모크: 모든 pending 상태와 메인/전력/게임오버/오류 토스트를 한 번씩 확인.

### 남은 일

- 커스텀 덱으로 대전하는 UI는 아직 없다. 현재는 추천 덱 14개 중에서만 고른다.
- 공격/대응/방어의 전체 브라우저 자동화는 렌더 테스트와 엔진 테스트로 대체했다.

## v0.4 — 2026-10-23 (카드 레이어 합성)

카드 이미지를 한 장으로 넣던 방식을 **프레임 + 일러스트 + 텍스트 합성**으로 바꿨다.
이제 텍스트를 고쳐도 이미지를 다시 만들 필요가 없다.

### 렌더링

- **3레이어 합성**: ① 프레임 `public/frames/<종류>.png` → ② 일러스트 `public/images/art/<카드ID>.png` → ③ 텍스트(HTML).
- 텍스트·수치·키워드는 `src/data/`에서 실시간으로 그린다. 카드 폭이 바뀌면 글자 크기를 자동으로 다시 맞춘다.
- `【…】` 키워드는 카드 위에서 금색으로 강조된다.
- 프레임/일러스트 파일이 없으면 CSS 프레임과 스트리머 색 플레이스홀더로 대체된다. 파일을 넣는 순간 적용된다.
- 빌드 시 `public/images/art`, `public/frames`를 스캔해 실제 파일만 연결한다. 이미지가 없는 카드가 404를 요청하지 않고, 개발 서버는 파일 추가 시 자동 새로고침된다.
- 카드 데이터에 `image`를 지정하면 기존처럼 완성 이미지 한 장으로 표시한다. (`art`는 일러스트 경로 오버라이드)
- 레이아웃 기준은 `src/data/frames.ts` 하나다. 일러스트 창은 카드의 가로 10–90%, 세로 14–70%.

### UI

- **카드 크기 전환**(작게·보통·크게) 추가.
- 카드를 누르면 **상세 모달**이 열린다. 큰 카드와 함께 출처·메모·스트리머 정보를 보여주고, Esc로 닫는다.
- 덱 빌더·로스터의 카드도 같은 합성 렌더링을 쓴다. (기존 축소 크롭 제거)

### 문서 갱신

- `public/images/README.md`: 카드 전체 이미지 → **일러스트** 규격으로 재작성. 일러스트 창 좌표와 정사각형 권장 크기 명시.
- `public/frames/README.md`: 신규. 프레임 크기·투명 창 좌표·파일명 규칙.
- README에 레이어별 수정 방법 표 추가.

### 공격 간격

- 공식 프로필의 **신장**을 전원 확인해 반영. (유니 150 / 후야 162.8 / 히나 156 / 마시로 160 / 리제 165 / 타비 150 / 시부키 157 / 린 160 /
  나나 142 / 리코 158 / 토아 157 / 랑 145 / 히요리 161 / 메리 159)
- **설정상 무기**를 정해 사거리 등급을 부여하고, 신장으로 최대 간격을 보정. 무기 특성이 신장보다 우선한다.
- **타비 2-6 → 2-5**, **나나 3-5 → 3-6**으로 조정. (신장 150cm 곡괭이 / 신장 142cm 권총)

### 시그니처 정리 (중복 제거)

- **시부키 「충전」**: 카드 사용으로 쌓고 같은 턴에 터뜨리는 폭발형.
- **랑 「기세」**: 피격·공격으로 쌓고 방어·반격에 쓰는 지속형. 충전과 트리거·용도가 반대.
- **히요리 「원한」**: 상대 턴 종료 시 지속 감소하는 소모형 저주.
- **메리 「불운」**: 상대의 드로우를 왜곡하는 즉발형 방해. 원한과 작동 시점이 다르다.
- 「표적」은 나나 전용으로 유지.

### 카드 이름

- 각 기술 카드 이름을 **나무위키 밈 또는 커버곡 이름**에서 차용하고, 각 스트리머 절 끝에 출처를 명시.
- 리제는 공식 무기가 없어 **송곳니(0-1)·무대 마이크(2-4)** 를 설정상 무기로 채택.

## v0.1.1 — 2026-10-23 (문서 검토 수정)

원작 룰 대조 및 문서 간 모순 수정.

### 규칙

- **첫 턴**: 선공뿐 아니라 **양쪽 플레이어 각자의 첫 턴**이 개시 페이즈를 건너뛰도록 수정. (원작과 동일)
- **부여패 감소**: "양쪽 플레이어의 모든 부여패" → **턴 플레이어의 부여패**로 수정. 상대 부여패는 상대 턴에만 감소.
- **패산 재구성**: "라이프 1을 플레어로" → **라이프 1 데미지**(라이프 → 플레어)로 명확화. 라이프 1에서 재구성하면 패배할 수 있음.
- **드로우 실패 페널티**: 개시 페이즈뿐 아니라 카드 효과로 뽑을 때도 적용됨을 명시.
- **회복**: 더스트 → 라이프로 정의. 더스트가 비면 회복 불가.
- **데미지**: 오라 데미지 0~5, 라이프 데미지 상한 없음, 감소 효과로 0 미만이 되면 0 처리.
- **라이프 데미지의 플레어**: 맞은 쪽(방어자)의 플레어로 이동함을 명시.

### 키워드

- **【종단】 → 【필중】**: 원작의 '종단(사용 후 이번 턴 종료)'과 혼동을 피하기 위해, '대응 불가'를 【필중】으로 개칭. 해당 카드 3장과 밸런스 문서 갱신.
- **【초극】**: 원작과 동일하게 "오라 데미지 상한(5) 제거"로 수정. 6 이상이면 오라로 받을 수 없음.
- **거리확대/축소**: 양쪽으로 확대/축소하는 단순화 규칙으로 정의를 통일하고 예시를 수정. (3-5에 거리축소 1 → 4)

### 카드

- **백설의 왈츠**: "이번 턴 상대는 전진/이탈 불가" → **상대의 다음 턴 동안** 불가로 수정. (자기 턴 제한은 실질적으로 의미가 없었음)
- **【상시】 자기 수정 카드**: 별의 궤적, 절대영도, 피의 손톱, 최후의 세레나데의 문장을 "이 공격은…"으로 통일.
- **발톱 연타**: `【전력】【상시】` → `【전력】 이 공격은…`으로 정리.

### 문서

- 시그니처를 "키워드"가 아닌 **"메커니즘"**으로 용어 정리. (전역 키워드가 아니라 카드 텍스트 내 조건/테마)
- 4기생 확장 시점을 README 로드맵과 일치. (기본판·1차 확장은 1~3기, 4기생은 2차 확장 이후)
- 하우스 룰을 `01_rules.md` 10-2에 명문화.
- 변경 이력 문서 생성.
