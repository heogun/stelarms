# 04. 밸런스 & 플레이테스트

> 목표: **"서로 다른 4개 축이 45~55% 승률로 맞물리는 게임"**
> 카드 한 장의 강함보다, **거리·템포·자원**의 상호작용을 측정한다.

---

## 1. 설계 목표

| 항목 | 목표 |
| --- | --- |
| 1인당 턴 수 | 7~10턴 |
| 게임 시간 | 15~25분 |
| 선공 승률 | 45~55% |
| 최악 매치업 | 40~60% 이내 (알파), 45~55% (최종) |
| 라이프 0 결착 | 전체 게임의 90% 이상 |
| "할 일 없는 턴" | 10% 이하 |
| 한 턴 고민 시간 | 평균 60초, 최대 2분 |

---

## 2. 파워 예산

### 2-1. 거리별 기본 스탯

| 주 거리 | 오라 데미지 | 라이프 데미지 | 비고 |
| --- | --- | --- | --- |
| 0–2 (근거리) | 2–3 | 1–2 | 이동 비용을 이미 지불한 상태. 화력 보상 |
| 3–4 (중거리) | 2–3 | 1–2 | 가장 안정적인 구간 |
| 5–6 (중거리) | 2 | 1–2 | 원거리 진입. 유틸리티가 강점 |
| 7–8 (원거리) | 1–2 | 1–2 | 접근당하기 전까지 일방적 |
| 9–10 (최원거리) | 1 | 1 | 초반 1~2턴만 유효. 그 후 무의미 |

> **원칙**: 거리가 멀수록 "지금 때릴 수 있는 권리"가 강하므로, 카드 자체의 화력은 낮춘다.

### 2-2. 데미지 총량

- **일반 공격**: 오라 1~3 / 라이프 0~2
- **비장패 공격**: 오라 2~4 / 라이프 2~3
- **피니셔**: 라이프 4까지 허용. 단 **[필중] + 소모 2 이상 + 조건** 중 2개 이상을 만족해야 한다.
- **2장 콤보**: 방어자가 실제로 받는 피해의 합이 6 이하 (각 공격에서 선택된 값 기준)
- **3장 콤보**: 방어자가 실제로 받는 피해의 합이 8 이하. 10을 한 턴에 지우는 콤보는 "올인" 전용으로만.

### 2-3. 비용 곡선

| 효과 | 대략적 가치 |
| --- | --- |
| 카드 1장 뽑기 | 오라 1 |
| 기본동작 1회 | 집중력 1 = 오라 1 |
| 거리 1 조정 | 오라 0.5 |
| 오라 1 회복 | 0.5 카드 |
| 라이프 1 회복 | 2~3 플레어 |
| 오라 데미지 +1 | 0.5 카드 |
| 라이프 데미지 +1 | 1 카드 |
| 【필중】 | 0.5 카드 |
| 【초극】 | 1 카드 |

> 이 표는 절대 기준이 아니라 "이 효과에 이 정도를 지불하게 하라"는 가이드다.

## 3. 덱 구축 가이드

### 3-1. 통상패 7장의 황금 비율

| 역할 | 장수 | 예시 |
| --- | --- | --- |
| 주력 거리 공격 | 3 | 3–5에서 때리는 카드 |
| 인접 거리 공격 | 1 | 상대가 붙었을 때 |
| 이동/드로우 | 1 | 전진·후퇴·드로우 |
| 부여(지속) | 1 | 화력 또는 방어 엔진 |
| 대응/유틸 | 1 | 방어, 견제, 서치 |

- 7장 중 **최소 4장은 실제로 데미지를 주는 카드**여야 한다.
- 7장 모두 같은 거리대면, 상대가 거리만 바꿔도 손패가 죽는다.
- "이 카드가 없으면 덱이 안 굴러간다"는 카드가 3장 이상이면, 그 카드가 밴/너프 1순위다.

### 3-2. 비장패 3장

| 역할 | 장수 |
| --- | --- |
| 피니셔 | 1 |
| 템포/압박 | 1 |
| 유틸/방어/회복 | 1 |

- 3장 모두 공격이면 플레어가 남아도 손패가 막힌다.
- 3장 모두 유틸이면 라이프를 깎을 수단이 없다.

### 3-3. 페어 설계

- **같은 거리대 2명**: 화력은 높지만, 상대가 거리를 바꾸면 둘 다 죽는다. (예: 마시로+리코)
- **다른 거리대 2명**: 유연하지만, 손패가 엇갈리면 템포를 잃는다. (예: 히나+마시로)
- **서포트 + 주력**: 후야/린을 넣으면 주력이 강해지지만, 서포트 자체의 승리 플랜이 약하다.

> 좋은 덱은 "주력 거리에서 70%의 턴을 보내고, 나머지 30%는 이동/방어"로 설계된다.

## 4. 매치업 매트릭스 (기본판 4인)

각 칸은 **왼쪽 스트리머 duo vs 위쪽 duo**의 예상 승률. 알파 기준.

| | 유니+리제 | 히나+마시로 | 마시로+리제 | 유니+히나 |
| --- | --- | --- | --- | --- |
| **유니+리제** | — | 55% | 50% | 60% |
| **히나+마시로** | 45% | — | 55% | 50% |
| **마시로+리제** | 50% | 45% | — | 55% |
| **유니+히나** | 40% | 50% | 45% | — |

> 이 표는 **가설**이다. 실제 측정으로 채운다. 50%에서 10% 이상 벌어지면 원인을 카드 1~2장으로 좁힌다.

## 5. 플레이테스트 프로토콜

### 5-1. 준비

- 프록시 카드(종이)로 진행. 아트는 나중.
- 4명 이상, 3라운드 스위스.
- 매 게임 전에 **양쪽 덱을 공개**하고, "이 조합이 어떤 플랜인지" 30초 설명.
- 룰 판정은 룰 담당 1명이 내린다. 애매하면 기록 후 임시 판정.

### 5-2. 기록 항목

| 항목 | 내용 |
| --- | --- |
| 날짜 / 테스터 | |
| 매치업 | A duo vs B duo |
| 선공 | |
| 승자 | |
| 남은 라이프 | |
| 총 턴 수 | |
| 사용한 비장패 | |
| 느낌 점수 (1~5) | "이 게임이 재미있었나" |
| 불쾌한 순간 | 있으면 1줄 |
| 룰 애매함 | 있으면 1줄 |

### 5-3. 측정 지표

| 지표 | 목표 | 문제 시 조치 |
| --- | --- | --- |
| 선공 승률 | 45~55% | 후공 보정(집중력 1) 재검토 |
| 평균 턴 수 | 7~10 | 5턴 이하 → 어그로 너프 / 12턴 이상 → 제어 너프 |
| 카드 채용률 | 20~80% | 80% 초과 → 너무 범용적 / 20% 미만 → 니치 |
| 매치업 승률 | 40~60% | 60% 초과 → 상성 카드 조정 |
| 한 턴 시간 | 60초 | 2분 초과 → 텍스트/선택지 단순화 |
| "재미 4~5" 비율 | 80% | 60% 미만 → 템포/상호작용 재검토 |

### 5-4. 테스트 순서

1. **룰 테스트 (5판)**: 룰이 돌아가는가. 카드 텍스트 오류, 무한 루프, 불가능한 상황.
2. **미러 테스트 (10판)**: 같은 duo vs 같은 duo. 선공 승률과 덱 안정성.
3. **상성 테스트 (각 10판)**: 4개 duo의 6개 조합.
4. **블라인드 테스트 (20판)**: 디자이너가 "이 덱이 이길 것"이라고 말하지 않고 진행.
5. **확장 테스트**: 8인 로스터로 넘어가기 전, 기본 4인이 45~55%에 들어오는지 확인.

> **20판 미만의 승률은 믿지 않는다.** 5판 연승/연패는 그냥 운이다.

## 6. 너프/버프 원칙

1. **원인을 너프하고, 결과를 너프하지 않는다.**
   - 콤보가 강하면 피니셔가 아니라 **콤보 시동 카드**를 만진다.
2. **한 번에 한 장만.**
   - 3장을 동시에 만지면 무엇이 효과가 있었는지 모른다.
3. **1점 단위로.**
   - 데미지 1, 비용 1, 거리 1. 텍스트를 전면 재작성하는 것은 최후의 수단.
4. **약한 카드는 "1점 버프"부터.**
   - 봉납 -1, 드로우 +1, 거리 +1. 새 키워드를 붙이지 않는다.
5. **금지 카드는 "게임을 망치는 카드"에만.**
   - 강한 카드는 밴이 아니라 너프. 밴은 루프/락/비상호작용에만.

## 7. 금지/주의 기준

### 즉시 금지 후보

- 상대가 카드를 사용할 수 없는 **하드 락**.
- 무한 루프(같은 카드가 계속 재사용되어 턴이 끝나지 않음).
- "이 카드를 쓰면 사실상 승리"하는 **비상호작용 콤보**.
- 한 플레이어가 **추가 턴**을 반복하는 효과.
- 덱을 무한히 재구성해 라이프 페널티를 무시하는 효과.

### 주의 후보

- 【필중】 + 라이프 4 + 소모 2 이하.
- "기본동작 2회 추가" + 드로우.
- "공격할 때마다 상대 오라 감소"처럼 **공격을 봉쇄**하는 지속 효과.
- "라이프 회복"이 2장 이상 들어간 덱. 게임이 길어진다.
- "상대 손패를 버리게 하는" 효과. 재미를 크게 해친다.

## 10. 밸런스 회의 운영

- 매주 1회, 30분.
- 안건은 **데이터 3개 + 체감 1개**로 제한.
- "강하다"가 아니라 "어떤 상황에서 강한가"를 말한다.
- 결정은 **1장 변경 + 10판 재측정**.
- 변경 이력은 [`changelog.md`](changelog.md)에 남긴다.

---

## 11. 확장 시 주의

- 8인 로스터가 되면 **"누가 최강인가"보다 "누가 누구를 잡는가"** 를 본다.
- 새 스트리머는 기존 4인 상대로 40~60%에 들어와야 한다.
- 새 시그니처 메커니즘이 기존 카드와 **의도치 않은 콤보**를 만드는지 확인한다.
- 14인 완성 시, "모든 조합"은 91가지다. 전수 테스트는 불가능하므로 **역할별 대표 duo** 8개로 압축한다.
