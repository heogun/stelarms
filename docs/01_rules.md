# 01. 코어 룰

> 원작 『벚꽃 내리는 시대에 결투를』의 코어 구조를 참고하되, STELARMS에 맞게 문장을 새로 쓴 룰이다.
> 카드 수치는 `cards/00_index.md`와 기수별 카드 문서(01~04)를, 밸런스 기준은 `04_balance_playtest.md`를 참조.

---

## 1. 게임 목표

상대의 **라이프를 0**으로 만들면 승리한다.
라이프는 곧 "팬심"이며, 공격은 상대의 **오라(텐션)** 를 깎거나 **라이프(팬심)** 를 직접 깎는다.

- 2인 대전, 1:1
- 플레이 시간 목표: **15~25분**
- 운 요소 최소화: 카드 뽑기 외의 무작위성 없음

---

## 2. 구성물

| 구성물 | 수량 | 비고 |
| --- | --- | --- |
| 스텔라 카드 | 14장 | 스트리머 선택용. 기본판은 4장 |
| 스킬 카드 | 스트리머당 11장 | 통상패 7 + 비장패 4 |
| 스텔라 크리스탈 토큰 | 플레이어당 30개 내외 | 라이프·오라·플레어·거리·더스트 공용 |
| 거리 트랙 | 1개 | 0~10 |
| 집중력 마커 | 플레이어당 1개 | 0~2 |
| 룰북 / 참조 카드 | 1부 | 키워드 요약 |

> 기본판(4명) = 스킬 카드 44장 + 스텔라 카드 4장 + 토큰. 두 명이 같은 스트리머를 골라도 되도록 **각 카드 2장씩** 인쇄하는 것을 권장한다.

| 플레어 | **플레어** | 유지 |
| 라이프 | **라이프** | 유지 |
| 더스트 | **더스트** | 유지 |

## 4. 게임 준비

### 4-1. 스텔라 선택 (쌍장요란)

1. 각 플레이어는 스텔라 14명 중 **2명**을 고른다.
2. 두 플레이어는 동시에 공개한다. 같은 스텔라를 골라도 무방하다.
3. (선택 규칙) **삼습일사**: 3명을 고르고, 상대가 그중 1명을 제외한다. 남은 2명으로 덱을 짠다. 토너먼트 권장.

> 2명 선택이 이 게임의 핵심이다. "주력 1명 + 보조 1명"이 기본이며, 두 명의 거리대가 겹치면 화력이 몰리고, 벌어지면 대응력이 생긴다.

### 4-2. 덱 구축 (안전구축)

상대의 2명을 확인한 뒤, **비공개로** 다음을 고른다.

- 고른 스텔라 2명의 **통상패 14장 중 7장**
- 고른 스텔라 2명의 **비장패 8장 중 3장**

| 구분 | 풀 | 선택 | 덱에서의 위치 |
| --- | --- | --- | --- |
| 통상패 | 14장 | 7장 | 패산에 섞는다 |
| 비장패 | 8장 | 3장 | 비장패 존에 뒷면으로 둔다 |

- 같은 이름의 카드를 2장 넣을 수 없다. 통상패 7장은 모두 다른 카드다.
- 선택하지 않은 카드는 게임 밖에 뒷면으로 둔다.
- 비장패는 상대에게 비공개. 사용하면 앞면이 되어 상대가 확인할 수 있다.

### 4-3. 초기 배치

| 영역 | 시작값 |
| --- | --- |
| 라이프 | **10** |
| 오라 | **3** (최대 5) |
| 플레어 | **0** |
| 거리 | **10** (최대 10) |
| 더스트 | 0 |
| 집중력 | 선공 0 / 후공 1 |
| 손패 | 3장 |

- 거리는 10에서 시작한다. 즉 **게임 시작 시 원거리 카드만 닿는다.** 근거리 스텔라는 전진으로 거리를 좁혀야 한다.
- 오라 최대 5. 초과하는 오라 획득은 초과분을 무시한다.
- 플레어에는 상한이 없다.

### 4-4. 선후공과 멀리건

1. 무작위로 선공을 정한다.
2. 각자 패산을 섞고 3장을 뽑는다.
3. 선공부터, 후공 순서로 각자 **1회씩** 원하는 만큼 손패를 패산 아래에 원하는 순서로 놓고, 그 수만큼 다시 뽑는다.
4. 선공 집중력 0, 후공 집중력 1.
5. **양쪽 플레이어 모두 각자의 첫 턴에는 개시 페이즈를 건너뛰고 메인 페이즈부터** 시작한다. (선공 1턴·후공 1턴 모두 드로우, 집중력 획득, 부여패 감소가 없다.)

### 4-5. 수치의 상한과 지불

| 수치 | 상한 | 초과 시 |
| --- | --- | --- |
| 라이프 | 10 | 초과분 무시 (회복 불가) |
| 오라 | 5 | 초과분 무시 |
| 거리 | 10 | 초과분 무시 |
| 집중력 | 2 | 초과분 무시 |
| 플레어 | 없음 | — |
| 손패 | 2 (종료 시) | 초과분을 덮음패로 |

- **라이프를 지불하는 효과**는 라이프가 1 이하일 때 사용할 수 없다. 지불로 라이프가 0이 되어 패배하는 것을 막기 위함이다. (하우스 룰)
- 카드 효과로 기본동작을 수행할 때, 이동이 불가능하면(오라 최대, 거리 최대, 오라 0 등) 이동하지 않고 나머지 효과만 처리한다.
- **회복**은 더스트의 크리스탈을 라이프로 옮긴다. 더스트에 크리스탈이 없으면 회복할 수 없다. 라이프 상한(10)을 넘을 수 없으며, 상한에서 회복을 시도하면 아무 일도 일어나지 않는다.

## 5. 턴 진행

```text
개시 → 메인 → 종료
```

### 5-1. 개시 페이즈

아래를 순서대로 수행한다.

1. **집중력 +1** (최대 2)
2. **부여패 감소**: **턴 플레이어**의 모든 부여패에서 크리스탈 1개를 더스트로 보낸다.
   - 상대의 부여패는 상대 턴의 개시 페이즈에만 감소한다.
   - 크리스탈이 0이 된 부여패는 **파기**되고, 【파기시】 효과를 해결한 뒤 버림패로 간다.
3. **패산 재구성 (선택)**: **라이프 1 데미지를 받고**(라이프 → 플레이어의 플레어), 버림패·덮음패·남은 패산을 모두 섞어 새 패산으로 만든다.
   - 라이프가 1일 때 재구성하면 라이프가 0이 되어 패배할 수 있다.
4. **2장 드로우** — 패산 위에서 2장을 뽑는다.
   - 패산이 비어 뽑을 수 없다면, 뽑지 못한 1장당 **오라 또는 라이프 1 데미지**를 받는다(자신이 선택).
   - 이 데미지는 공격이 아니므로 【대응】할 수 없다.
   - 이 페널티는 개시 페이즈의 2장 드로우뿐 아니라, 카드 효과로 뽑을 때도 적용한다.

> 양쪽 모두 각자의 첫 턴에는 이 단계 전체를 건너뛴다. 따라서 선공 1턴과 후공 1턴에는 드로우도, 집중력 획득도, 부여패 감소도 없다.

### 5-2. 메인 페이즈

둘 중 하나를 선택한다.

| 행동 | 내용 |
| --- | --- |
| **표준 행동** | 카드 사용과 기본동작을 **원하는 순서로** 수행. 카드 사용은 자원과 조건이 허락하는 만큼, 기본동작은 **턴당 1회 + 카드 효과로 얻은 추가 횟수**. 【전력】 카드는 사용 불가. |
| **전력 행동** | **카드 1장만** 사용. 【전력】 카드 사용 가능. 기본동작 불가. |

- 카드 사용은 손패의 카드 1장 또는 미사용 비장패 1장을 사용하는 것이다.
- 기본동작은 아래 5종이며, 각각 **집중력 1** 또는 **손패 1장을 덮음패로** 지불해 수행한다.
- 기본동작은 **턴당 기본 1회**만 가능하다. "이번 턴 기본동작 1회 추가" 효과로 횟수를 늘릴 수 있으며, 추가된 횟수도 코스트를 **면제**하지 않는다.
- 기본동작과 카드 사용은 서로의 횟수를 소모하지 않는다. 기본동작을 쓴 뒤에도 카드는 계속 사용할 수 있다.

### 5-3. 종료 페이즈

- 손패가 3장 이상이면 **2장이 되도록** 초과분을 덮음패로 놓는다.
- 덮음패는 뒷면 가로로 놓는다. 상대는 볼 수 없고, 자신은 볼 수 있다.

## 6. 기본동작 5종

| 동작 | 크리스탈 이동 | 효과 | 제한 |
| --- | --- | --- | --- |
| **전진** | 거리 → 오라 | 거리 -1, 오라 +1 | 거리 2 이하에서는 불가. 오라가 최대면 불가. |
| **후퇴** | 오라 → 거리 | 오라 -1, 거리 +1 | 오라 0이면 불가. 거리 10이면 불가. |
| **휘감기** | 더스트 → 오라 | 오라 +1 | 오라가 최대면 불가. 더스트 0이면 불가. |
| **품기** | 오라 → 플레어 | 플레어 +1 | 오라 0이면 불가. |
| **이탈** | 더스트 → 거리 | 거리 +1 | **거리 2 이하에서만** 가능. 거리 10이면 불가. |

- **달인의 거리 = 2.** 거리 2 이하에서는 전진할 수 없고, 대신 이탈로 벗어난다.
- 기본동작의 코스트는 **집중력 1** 또는 **손패 1장 덮기** 중 하나.
- 기본동작은 **턴당 기본 1회**이며, 카드 효과로 얻은 추가 횟수만큼 더 수행할 수 있다.
- 이동 결과가 불가능하면(예: 오라 최대에서 전진) 그 동작을 선택할 수 없다.

## 7. 카드 사용과 데미지

### 7-1. 카드 타입

| 타입 | 프레임 | 설명 |
| --- | --- | --- |
| **공격** | 빨강 | 적정거리 안에서만 사용. 명시된 데미지를 준다. |
| **행동** | 파랑 | 단발 효과. 사용 후 버림패. |
| **부여** | 초록 | 봉납만큼 크리스탈을 올려 부여패 존에 둔다. 지속 효과. |

### 7-2. 공격의 데미지

공격 카드의 데미지는 **`오라 데미지 / 라이프 데미지`** 로 표기한다.
예: `3/1` = 오라 3, 라이프 1.

방어자는 둘 중 하나를 선택한다.

1. 양쪽이 정수라면, 방어자가 오라 또는 라이프를 선택.
2. **현재 오라 < 오라 데미지**라면 오라를 선택할 수 없다. → 라이프로 맞는다.
3. 한쪽이 `-`라면, `-`가 아닌 쪽을 반드시 선택한다.
4. 양쪽이 `-`라면 아무 일도 일어나지 않는다.

#### 데미지 해결

- 오라 데미지: **방어자의 오라**에서 해당 수만큼 크리스탈을 **더스트로** 보낸다.
- 라이프 데미지: **방어자의 라이프**에서 해당 수만큼 크리스탈을 **방어자의 플레어로** 보낸다.
  - 라이프가 0이 되면 즉시 패배.
- 오라 데미지는 **0~5**로 처리한다. 5를 초과하는 오라 데미지는 5가 된다.
- 라이프 데미지에는 상한이 없다.
- 【초극】 키워드가 있으면 오라 데미지의 상한(5)이 사라진다. 오라 데미지가 6 이상이면 방어자는 오라를 선택할 수 없고(오라 최대 5), 라이프로 받아야 한다.
- 데미지 감소 효과로 0 미만이 되면 0으로 처리한다.

> 핵심 심리전: 상대 오라가 3인데 `4/1` 공격을 맞으면 오라를 선택할 수 없어 라이프 1을 맞는다. 그래서 "오라 4 이상 유지"가 방어의 기본이 된다.

### 7-3. 적정거리

- `3-4` = 거리 3 또는 4에서 사용 가능.
- `4, 6` = 거리 4 또는 6에서만.
- `5-` = 5 이상 전부.
- 카드 효과로 거리 범위를 넓히거나(`거리확대`), 좁힐 수 있다(`거리축소`).

### 7-4. 부여패

1. 사용 시 **봉납 N**만큼 오라와 더스트에서 크리스탈을 가져와 카드 위에 올린다.
   - 합계가 N보다 부족하면 사용할 수 없다. (원작은 부족한 만큼만 올리고 사용할 수 있지만, STELARMS는 계산을 단순화하기 위해 사용 불가로 한다.)
2. 카드는 **부여패 존**에 앞면 세로로 둔다.
3. 【전개중】 효과가 계속 적용된다.
4. 각 턴의 개시 페이즈마다, **턴 플레이어의 모든 부여패**에서 크리스탈 1개를 더스트로 보낸다. 상대의 부여패는 상대 턴에 감소한다.
5. 마지막 크리스탈이 사라지면 **파기** → 【파기시】 해결 → 버림패.

### 7-5. 비장패

- 게임 중 **1회만** 사용 가능. 사용 후 앞면으로 비장패 존에 남는다.
- 사용하려면 **플레어를 소모값만큼 지불**한다.
- 【재기】 키워드가 있으면 조건을 만족할 때 다시 뒷면으로 돌려 재사용할 수 있다.
- 【전력】 키워드가 있으면 **전력 행동**에서만 사용할 수 있다.
- 비장패는 버림패로 가지 않으며, 패산 재구성에도 섞이지 않는다.

| --- | --- |
| **【상시】** | 이 카드가 해당 영역에 있는 동안 항상 적용. |
| **【공격후】** | 공격의 데미지 해결이 끝난 뒤 1회 발동. |
| **【전개중】** | 부여패가 존에 있는 동안 적용. |
| **【파기시】** | 부여패가 파기될 때 1회 발동. |
| **【대응】** | 상대 턴에 조건을 만족하면 사용 가능. 주로 공격 선언 후 데미지 해결 전. |
| **【전력】** | 전력 행동에서만 사용 가능. 표준 행동에서는 사용 불가. |
| **【필중】** | 이 카드의 사용에는 【대응】할 수 없다. (원작의 '대응 불가'에 해당) |
| **【초극】** | 이 공격의 오라 데미지 상한(5)을 없앤다. 6 이상이면 방어자는 오라를 선택할 수 없다. |
| **【재기】** | 조건을 만족하면 사용한 비장패를 미사용 상태로 되돌린다. |
| **거리확대 N** | 적정거리의 최솟값을 N만큼 낮추고, 최댓값을 N만큼 높인다. 예: 3-4에 거리확대 1 → 2-5. |
| **거리축소 N** | 적정거리의 최솟값을 N만큼 높이고, 최댓값을 N만큼 낮춘다. 범위가 비면 사용할 수 없다. 예: 3-5에 거리축소 1 → 4. |

> 원작은 거리확대/축소를 근/원 방향으로 나누지만, STELARMS는 양쪽으로 확대/축소하는 것으로 단순화한다.
> 새 키워드는 스트리머당 최대 1개까지만 추가한다. 키워드가 많아지면 참조 카드가 필요해져 진입 장벽이 높아진다.

## 10. 원작과 다른 점 (변경안)

| 항목 | 원작 | STELARMS | 이유 |
| --- | --- | --- | --- |
| 캐릭터 | 여신 | 스트리머 | 프로젝트 목적 |
| 카드 풀 | 여신 11장 | 스트리머 11장 | 구조 유지 |
| 덱 | 10장 | 10장 | 구조 유지 |
| 거리 시작 | 10 | 10 | 구조 유지 |
| 패산 고갈 | 위축 상태 | 단순 데미지 페널티 | 진입 장벽 완화 |
| 동시 사망 | 규정 있음 | 무승부 처리 | 단순화 |
| 시그니처 | 없음(카드 풀로 표현) | 스트리머별 시그니처 메커니즘 1개 | 캐릭터성 강화 |
| 합방 보너스 | 없음 | 선택 규칙 | 팬게임 재미 |
| 삼습일사 | 있음 | 선택 규칙 | 토너먼트용 |

### 10-1. 시그니처 메커니즘 설계 원칙

- 그 스트리머의 **공식 설정**에서만 뽑는다. 팬덤 밈은 보조적으로만.
- 새 전역 규칙을 만들지 않고, **그 스트리머의 카드 텍스트 안에서만** 완결된다.
- 상대가 그 메커니즘을 몰라도 카드 텍스트만 읽으면 이해할 수 있어야 한다.
- 한 스트리머의 시그니처가 다른 스트리머 카드에 붙지 않는다.
- 시그니처는 정식 키워드가 아니라 **메커니즘**이다. (예: 유니의 '각성'은 라이프 5 이하에서 켜지는 자기 강화 조건이다.)

### 10-2. STELARMS 하우스 룰

원작과 의도적으로 다르게 운용하는 부분이다. 테스트 후 필요하면 되돌린다.

- **기본동작 횟수**: 기본동작은 턴당 1회이며, 카드 효과로만 추가된다. (원작은 자원이 허락하는 만큼 여러 번 수행할 수 있다.)
- **기본동작 추가 코스트**: 카드 효과로 얻은 추가 기본동작도 집중력/손패 코스트를 지불한다. (원작은 카드 효과로 수행하는 기본동작의 코스트를 면제한다.)
- **봉납 부족**: 봉납 N을 완전히 지불하지 못하면 부여패를 사용할 수 없다. (원작은 가능한 만큼만 올리고 사용한다.)
- **거리확대/축소**: 근/원 방향 구분 없이 양쪽으로 확대/축소한다.
- **라이프 지불 금지**: 라이프가 1 이하일 때 라이프를 지불하는 효과를 사용할 수 없다.
- **패산 고갈**: 원작의 '위축' 대신, 뽑지 못한 1장당 오라/라이프 1 데미지.
- **【필중】**: 원작의 '종단(사용 후 이번 턴 종료)'이 아니라 '대응 불가'를 뜻한다. 혼동을 피하기 위해 이름을 바꿨다.

## 11. 선택 규칙

### 11-1. 합방 보너스 (캐주얼 전용)

같은 기수 스트리머 2명을 골랐다면, 게임 시작 시 **플레어 1**을 얻는다.

- 1기: 유니·후야
- 2기: 히나·마시로·리제·타비
- 3기: 시부키·린·나나·리코
- 4기: 토아·랑·히요리·메리

> 같은 기수 조합은 서사적으로 멋지지만, 최적 조합과는 거리가 있을 수 있다. 캐주얼 모드에서 "합방"의 로망을 보상한다. 토너먼트에서는 사용하지 않는다.

### 11-2. 삼습일사 (토너먼트 권장)

1. 각자 스텔라 3명을 고른다.
2. 상대가 그중 1명을 제외한다.
3. 남은 2명으로 덱을 구축한다.

> 상대의 3명을 보고 밴을 고르므로, "무조건 이 조합"을 방지하고 사이드 대응력을 본다.

### 11-3. 보스전: 사장님 강지 (이벤트용)

- 2인 협동 vs 강지 1인.
- 강지: 라이프 20, 오라 5, 플레어 3 시작. 턴마다 메인 페이즈 2회.
- 강지의 덱은 전용 20장(추후 제작).
- 협동 플레이어는 각자 1명씩 스텔라를 골라 덱을 만든다. 라이프는 공유하지 않는다.
- 강지의 라이프를 0으로 만들면 승리. 한 명이라도 라이프 0이면 패배.

> 밸런스보다 이벤트성 재미를 우선한다. 대회에서는 사용하지 않는다.

## 12. 자주 나오는 판정

**Q.** 오라가 5(최대)인데 전진할 수 있나?
A. 없다. 오라가 최대면 전진을 선택할 수 없다.

**Q.** 거리 2에서 후퇴할 수 있나?
A. 가능하다. 오라를 1 지불하고 거리 3으로 벌어진다. 단, 오라가 0이면 불가.

**Q.** 거리 2에서 전진은?
A. 불가. 대신 이탈(더스트→거리)로 3으로 벌어질 수 있다.

**Q.** 부여패의 크리스탈이 0이 되는 즉시 파기되나?
A. 개시 페이즈에 1개를 빼서 0이 되면, 그 시점에 파기하고 【파기시】를 해결한다.

**Q.** 비장패를 같은 턴에 2장 쓸 수 있나?
A. 플레어가 충분하고 표준 행동이라면 가능하다. 단 각 비장패는 1회뿐이다.

**Q.** 【필중】 공격에 【대응】 카드를 쓸 수 있나?
A. 불가. 필중은 대응 자체를 막는다. (원작의 '대응 불가'와 같다.)

**Q.** 【초극】 공격을 오라로 받을 수 있나?
A. 오라 데미지가 5 이하라면 받을 수 있다. 6 이상이면 오라 최대 5로는 부족하므로 라이프로 받아야 한다.

**Q.** 라이프를 회복할 때 크리스탈은 어디서 오나?
A. 더스트에서 가져온다. 더스트가 비어 있으면 회복할 수 없다.

**Q.** 부여패의 크리스탈은 누구 턴에 줄어드나?
A. 각자의 턴 개시 페이즈에, 턴 플레이어의 부여패만 1개씩 줄어든다. 상대의 부여패는 내 턴에 줄지 않는다.

**Q.** 기본동작은 한 턴에 몇 번 할 수 있나?
A. 기본 1회다. "기본동작 1회 추가" 효과를 받으면 그 횟수만큼 더 할 수 있다. (하우스 룰)

**Q.** 카드 효과로 얻은 추가 기본동작도 코스트를 내나?
A. 낸다. STELARMS에서는 횟수만 늘어나고, 집중력 1 또는 손패 1장은 그대로 지불한다. (하우스 룰)

**Q.** 후공도 첫 턴에 드로우를 못 하나?
A. 그렇다. 양쪽 모두 각자의 첫 턴에는 개시 페이즈를 건너뛴다. 선공 1턴·후공 1턴이 끝난 뒤부터 정상적으로 드로우한다.

**Q.** 공격 데미지 `-/-`는?
A. 아무 일도 일어나지 않는다. 효과만 해결한다.

**Q.** 라이프 데미지를 오라로 바꿀 수 있나?
A. 없다. 방어자는 카드에 적힌 두 값 중 하나를 고르는 것이지, 값을 변환하는 것이 아니다.

**Q.** 라이프 데미지를 받으면 누가 플레어를 얻나?
A. 맞은 쪽(방어자)이 얻는다. 라이프에서 빠진 크리스탈은 방어자의 플레어로 간다. 공격자는 별도 효과가 없다면 플레어를 얻지 않는다.
