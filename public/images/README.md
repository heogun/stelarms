# 카드 일러스트

카드는 **프레임 + 일러스트 + 텍스트**를 겹쳐서 그린다. 이 폴더에는 그중 **일러스트만** 넣는다.
카드 이름·수치·효과 텍스트는 `src/data/`의 값을 앱이 실시간으로 그리므로, 문구를 고쳐도
이미지를 다시 만들 필요가 없다.

## 파일 규칙

- 위치: `public/images/art/<카드ID>.<확장자>` (예: `public/images/art/YU-N-1.png`)
- 형식: PNG 권장. JPG / WebP / AVIF도 파일명만 맞으면 자동 인식한다.
- 파일이 없으면 스트리머 색 플레이스홀더가 대신 표시된다. 파일을 넣는 순간 그 카드만 바뀐다.
- 빌드 시 폴더를 스캔해 **실제로 있는 파일만** 불러온다. 그래서 이미지가 없는 카드가
  콘솔에 404를 쌓지 않고, 개발 서버는 파일을 추가하면 자동으로 새로고침된다.

카드 ID는 `docs/cards/*.md`의 번호 열과 `src/data/cards/*.ts`의 `id`에 있다.
번호 `N`은 통상패, `S`는 비장패다. (예: `RK-N-5`, `RK-S-2`)

| 접두어 | 스트리머 | 접두어 | 스트리머 |
| --- | --- | --- | --- |
| YU | 아야츠노 유니 | SH | 텐코 시부키 |
| HU | 사키하네 후야 | RI | 아오쿠모 린 |
| HI | 시라유키 히나 | NA | 하나코 나나 |
| MA | 네네코 마시로 | RK | 유즈하 리코 |
| LI | 아카네 리제 | TO | 시즈키 토아 |
| TA | 아라하시 타비 | RA | 코가네 랑 |
| | | HY | 하나요 히요리 |
| | | ME | 토키노 메리 |

## 일러스트 창

프레임에서 일러스트가 보이는 영역은 카드 크기의 **가로 10–90%, 세로 14–70%**다.
`src/data/frames.ts`의 `art` 값으로 정의되어 있다.

| 항목 | 값 |
| --- | --- |
| 창 크기 | 카드의 80% × 56% → **거의 정사각형** |
| 권장 이미지 | **750 × 750 px** (300 DPI 기준) |
| 최소 이미지 | 375 × 375 px |
| 인쇄 고려 | 1000 × 1000 px 이상 |
| 형식 | PNG, sRGB |

- 화면에서는 `object-fit: cover`로 **중앙 크롭**한다. 정사각형으로 그리면 잘리지 않는다.
- 인물이 잘리지 않게 하려면 **얼굴·상반신을 중앙**에 두고, 상하좌우 여백을 조금 남긴다.
- 창 비율을 바꾸고 싶으면 `src/data/frames.ts`의 `art`를 고친다. 프레임 이미지를 쓴다면
  같은 비율로 투명 창을 뚫어야 한다. 자세한 내용은 [프레임 문서](../frames/README.md) 참고.

## 카드 전체를 한 장으로 쓰고 싶다면

기존처럼 완성된 카드 이미지를 통째로 쓰는 방식도 남아 있다. 카드 데이터에 `image`를 지정하면
프레임·텍스트 합성을 건너뛰고 그 이미지만 표시한다.

```ts
{ id: "YU-N-1", /* … */ image: "/images/YU-N-1.png" }
```

일반적인 수정은 `art`만 쓰는 쪽이 훨씬 편하다. 텍스트를 고칠 때 이미지를 다시 뽑지 않아도 되기 때문이다.

## 확장판

새 스트리머를 추가하면 접두어를 하나 더 정하고, `src/data/stellas.ts`의 `code`와 카드 ID를 맞춘다.
