# 카드 프레임

프레임은 카드에서 **일러스트와 텍스트를 제외한 장식 레이어**다. 테두리, 등급 표시, 질감 등을 담는다.
이미지를 넣지 않아도 CSS로 그린 기본 프레임이 표시되므로, 디자인이 준비되면 파일만 넣으면 된다.

## 파일 규칙

- 위치: `public/frames/normal.png`, `public/frames/special.png`
- 크기: **750 × 1050 px** (카드 비율 63:88, 300 DPI)
- 형식: PNG, **알파 채널 필수**, sRGB
- 파일이 없으면 CSS 프레임으로 자동 대체된다. 파일을 추가하면 개발 서버가 자동으로 새로고침된다.

| 파일 | 용도 |
| --- | --- |
| `normal.png` | 통상패 98장 |
| `special.png` | 비장패 56장 |

## 일러스트 창 (투명 구멍)

프레임은 카드 전체를 덮는 이미지다. 일러스트가 보여야 하는 부분은 **투명하게 뚫어** 둔다.

| 위치 | 범위 |
| --- | --- |
| 가로 | 카드 폭의 **10% – 90%** |
| 세로 | 카드 높이의 **14% – 70%** |
| 픽셀 (750×1050) | x 75–675, y 147–735 |
| 창 비율 | 600 × 588 px (거의 정사각형) |

```text
0%   ┌────────────────────┐
     │  상단: 종류·이름     │ 0–14%
14%  ├────────────────────┤
     │                    │
     │   일러스트 창       │ 14–70%
     │   (투명)           │
70%  ├────────────────────┤
     │  하단: 수치·효과     │ 70–100%
0%   └────────────────────┘
     10%               90%
```

- 상단 0–14%는 카드 종류·이름·ID가, 하단 70–100%는 거리·데미지·효과 텍스트가 앱에서 그려진다.
- 이 두 영역에 프레임 이미지로 배경을 깔아도 되고, 완전히 비워 두어도 된다.
  (앱이 가독성을 위해 하단에 반투명 패널을 깔기 때문에, 프레임은 테두리 위주로 디자인하면 된다.)
- 안전 여백: 가장자리 4% 안쪽에 중요한 장식을 둔다.

## 창 비율 바꾸기

레이아웃의 기준값은 `src/data/frames.ts` 하나뿐이다.

```ts
normal: {
  id: "normal",
  label: "통상패",
  image: "/frames/normal.png",
  art: { top: 14, right: 10, bottom: 30, left: 10 },
},
```

`art`의 단위는 카드 크기 대비 %다. 이 값을 바꾸면 앱의 일러스트 위치와 프레임의 투명 창을
같은 비율로 맞춰야 한다. 기수별·스트리머별로 다른 프레임을 쓰려면 `frameFor()`에서 분기한다.

```ts
export function frameFor(card: Card): Frame {
  if (card.stellaId === "shibuki") return frames.special;
  return frames[card.kind];
}
```

## 텍스트는 이미지에 넣지 않는다

카드 이름·수치·효과는 `src/data/`의 값을 HTML로 그린다. 프레임에 글자를 구워 넣으면
밸런스 수정 때마다 이미지를 다시 뽑아야 하므로, **프레임에는 글자를 넣지 않는다.**
